# Osprey 1.2.0 更新公告

发布日期：2026-11-03

## 全新深色界面

主编辑器改成纯 Python Tkinter/ttk 的深色主题，不引入 C 或额外运行时：

- 深色背景、卡片式区块、统一边框和间距
- 表格、输入框、下拉框、日志区全部深色适配
- 顶部品牌区、状态栏保留
- AI 指令框同步深色，输入区和按钮更清晰

安装包体积基本不变。

## 这次同时修复

- **AI 对话框底部按钮被裁切**：内容高度 796px 超过窗口 760px，已调整输入框高度和窗口尺寸，试运行/真实运行按钮完整可见。
- **取消模型下载崩溃**：关闭窗口会取消启动回调，下载线程不再访问已销毁的 Tk 控件。
- **选中 3B/7B 自动检查并提示下载**：显示 3B 约 3 GB / 7B 约 6 GB，确认后进度条，可取消。
- **不再自动下载模型**。

## 本地 Qwen-VL

- 支持 3B（能用）/ 7B（精准）
- 截图 + OCR 编号标注
- 模型只选 element_id，点击使用 OCR 框中心
- 需要安装 Ollama；模型下载可取消
