# Osprey 1.1.3 更新公告

发布日期：2026-11-02

## 这次修复

**AI 指令框在窄窗口下不再横向拥挤。**

- 模型选择拆成两行：DeepSeek 文本一行，本地 Qwen-VL 3B/7B 一行
- 指令文本框宽度从 80 字符收窄到 60 字符
- 对话框请求宽度从约 992px 降到约 752px，800px 窗口下能完整显示

## 保留的本地模型行为

- 3B 约 3 GB，7B 约 6 GB，界面明确标注
- 不会自动下载；只有点“下载所选本地模型”并确认后才开始
- 下载中可点“取消下载”，关闭窗口也会停止
- 运行前模型缺失只提示，不偷偷下载
