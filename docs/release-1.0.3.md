# Osprey 1.0.3 更新公告

发布日期：2026-11-01

## 这次修复

**API Key 无效时，AI 不会再空跑 30 步。**

之前 DeepSeek 返回 401/403，AI 只记录一条警告，然后继续 OCR、继续请求，直到 30 步上限，既浪费时间也可能反复触发失败请求。

现在遇到认证失败会立即停止，并明确提示：

    DeepSeek authentication failed

其他网络错误仍会按原逻辑等待重试，不会因为一次超时就直接退出。

## 包含的 1.0.2 内容

- AI 底部小按钮细扫，能识别「上一节 / 下一节」
- 中文 OCR 空格归一化，支持「下一页 / 下一节 / Next」语义匹配
- 修复安装版 OCR 的 WinError 50
- AI 支持 scroll，滚动前把鼠标移到屏幕中心
- OCR 连续失败 3 次立即停止
- 无中文 OCR 语言包时回退系统语言
- AI 运行时最小化编辑器，OCR 看整个桌面

- Osprey-1.0.3-Setup.exe：安装版

## 已知限制

- AI 底部细扫会让单帧 OCR 约 19 秒，准确性优先。
- AI 需要 DeepSeek API Key。
- DeepSeek 文本模型看到的是 OCR 文本，不是截图。
