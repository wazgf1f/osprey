# Osprey 1.0.2 更新公告

发布日期：2026-11-01

## 这次更新解决了什么

1. **AI 能找到底部小按钮了**
   Windows OCR 原先会漏掉「上一节 / 下一节」这类蓝底白字的小按钮。现在会对屏幕下半部分做 4 倍放大、自动对比度、分块 OCR，再与全屏结果合并去重。

2. **中文文本不再被空格拆散**
   OCR 返回的「下 一 节」会归一化成「下一节」，AI 能把它和指令里的「下一页」做语义匹配。

3. **修复安装版 OCR 的 WinError 50**
   打包后的 exe 不再使用不受支持的 CREATE_NO_WINDOW，改用 STARTUPINFO 隐藏 PowerShell 窗口。此前这个问题会让 AI 每一帧 OCR 都失败。

4. **AI 会滚动页面**
   新增 scroll 动作，目标不在当前画面时可以先滚动；滚动前会把鼠标移到屏幕中心，确保滚轮作用在页面上。

5. **OCR 连续失败会及时停止**
   连续 3 次 OCR 失败直接停止并报错，不再空跑到 30 步上限。

6. **英文/其他语言 Windows 也能 OCR**
   没有中文 OCR 语言包时，回退到用户配置语言，而不是返回空文本。

7. **AI 运行时会最小化编辑器**
   OCR 看到的是整个桌面，而不是 Osprey 自己挡住了目标窗口。

## 其他修复

- OCR 结果改为 UTF-8 文件输出，避免控制台代码页导致中文乱码。
- 修复 RapidOCR 初始化失败时不会回退 Windows OCR 的问题。
- DeepSeek 模型不支持 JSON 模式时自动重试普通模式。
- 缺少 API Key、OCR 后端不可用时输出干净的错误，不再打印 traceback。

## 升级说明

安装版会先解压到临时目录，再整体替换旧安装目录；桌面和开始菜单快捷方式会自动更新。卸载项显示为 Osprey 1.0.2。

## 已知限制

- AI 的底部细扫会增加单帧 OCR 时间，当前实测约 19 秒/帧，这是准确性优先的取舍。
- AI 仍需要 DeepSeek API Key；在编辑器的「AI 指令…」里填写，或设置 DEEPSEEK_API_KEY。
- DeepSeek 文本模型看到的是 OCR 文本，不是截图；OCR 读不出的文字，模型也无法理解。

## 反馈

如果 AI 点错或理解错，请附上：

- 日志最后一条 click ...
- 目标按钮文字
- 实际点击位置

这些信息能帮助定位是 OCR 框、坐标换算还是模型选择的问题。
