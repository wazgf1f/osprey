# Osprey 1.0.4 更新公告

发布日期：2026-11-01

## 这次修复

1. **滚动落点改为 OCR 内容的中位位置**
   之前滚动前会把鼠标移到整个虚拟桌面的中心；多显示器、或目标窗口不在桌面正中时，中心可能落在两屏之间或空白区域，滚轮到不了页面。现在用当前 OCR 元素坐标的中位数作为落点，优先落在真实内容上。

2. **模型返回 Infinity 时不再让 AI 抛异常**
   如果模型返回的 scroll amount 是无穷大，旧代码会在转换整数时抛 OverflowError，导致整个任务报错。现在会回退到默认滚动量。

## 包含的 1.0.3 / 1.0.2 内容

- API Key 无效时立即停止，不再空跑 30 步
- AI 底部小按钮细扫，能识别「上一节 / 下一节」
- 中文 OCR 空格归一化，支持「下一页 / 下一节 / Next」语义匹配
- 修复安装版 OCR 的 WinError 50
- AI 支持 scroll，OCR 连续失败 3 次立即停止
- 无中文 OCR 语言包时回退系统语言
- AI 运行时最小化编辑器，OCR 看整个桌面
