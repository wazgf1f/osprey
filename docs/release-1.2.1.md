# Osprey 1.2.1 更新公告

发布日期：2026-11-03

## UI 动效

- **窗口启动淡入**：打开编辑器时从透明平滑显示
- **标题栏流光**：顶部深色栏底部有一条循环移动的蓝色光线
- **按钮悬停渐变**：主按钮鼠标移入/移出时颜色平滑过渡
- **运行状态呼吸灯**：任务运行时左下角状态点缓慢明暗脉动
- **进度条**：本地模型下载显示百分比进度

动画只在主线程用 Tk 的 after 调度，窗口关闭时会取消，不会留下后台回调。

## 同时包含

- 1.2.0 的深色 Python UI
- AI 对话框按钮不再被裁切
- 取消模型下载不崩溃
- 选中 3B/7B 自动提示下载、显示大小、进度条、可取消
- 不自动下载模型
