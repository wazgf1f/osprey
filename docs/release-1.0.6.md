# Osprey 1.0.6 更新公告

发布日期：2026-11-01

## 这次改进

**减少 AI 看到的重复 OCR 元素。**

底部小按钮细扫会同时产生「整行文字」和「局部片段」两个 OCR 结果，它们位置重叠但文字长度不同。之前只有完全相同文字的框会去重，AI 会同时看到整行和片段，容易选到信息不完整的元素，或者点错位置。

现在：

- 位置重叠且文本互相包含的 OCR 元素会合并
- 保留文字更长的那个，通常信息更完整
- 并列的独立按钮（如「上一节」「下一节」）不会被误合并

## 包含的 1.0.5 / 1.0.4 / 1.0.3 / 1.0.2 内容

- OCR 分块超时只跳过该块，不再让整帧失败
- AI 滚动落点改为 OCR 元素中位位置，多显示器下可用
- API Key 无效时立即停止
- AI 底部小按钮细扫，能识别「上一节 / 下一节」
- 中文 OCR 空格归一化，支持「下一页 / 下一节 / Next」
- 修复安装版 OCR 的 WinError 50
- OCR 连续失败 3 次立即停止
- 无中文 OCR 语言包时回退系统语言
- AI 运行时最小化编辑器
