# Osprey 1.1.2 更新公告

发布日期：2026-11-02

## 这次调整：模型不再自动下载

本地 Qwen-VL 的模型下载改为**用户显式操作**：

- 不再在运行任务时偷偷执行 ollama pull
- AI 对话框显示两档大小：
  - **3B：约 3 GB**（能用）
  - **7B：约 6 GB**（精准）
- 点 **下载所选本地模型** 后，会再次弹出确认框，明确显示将下载的大小
- 只有确认后才开始下载
- 如果运行时模型还没下载，只提示“请先下载”，不会自动开始
- 下载过程中可以点 **取消下载**，关闭对话框也会停止下载进程

这样不会在用户不知情时占用几个 GB 的磁盘和带宽。

## 使用方式

1. 安装 [Ollama](https://ollama.com/download)。
2. 打开 **AI 指令…**，选择本地 Qwen-VL 3B 或 7B。
3. 点 **下载所选本地模型**，确认大小，等待完成。
4. 再点试运行/真实运行。

## 包含的本地视觉能力

- 整屏截图 + OCR 编号标注
- Qwen-VL 只返回 element_id
- 点击使用 OCR 框中心，不让模型猜像素
- F12 可中止 OCR 和模型下载
