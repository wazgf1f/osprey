# Osprey 1.0.5 更新公告

发布日期：2026-11-01

## 这次修复

**单个 OCR 分块超时不再让整帧 OCR 失败。**

底部小按钮细扫会启动多个 PowerShell OCR 子进程。之前如果其中某个子进程卡住，TimeoutExpired 不是 OcrError，细扫的异常处理接不住，整帧 OCR 会直接失败。

现在：

- 子进程超时会转换成 OcrError
- 细扫的单个分块超时只跳过该块，其他块继续
- 分块超时收紧到 10 秒，避免一个块拖住整帧

## 包含的 1.0.4 / 1.0.3 / 1.0.2 内容

- AI 滚动落点改为 OCR 元素中位位置，多显示器下仍能滚到目标窗口
- 模型返回 Infinity 时回退默认滚动量
- API Key 无效时立即停止，不再空跑 30 步
- AI 底部小按钮细扫，能识别「上一节 / 下一节」
- 中文 OCR 空格归一化，支持「下一页 / 下一节 / Next」
- 修复安装版 OCR 的 WinError 50
- OCR 连续失败 3 次立即停止
- 无中文 OCR 语言包时回退系统语言
- AI 运行时最小化编辑器
