# Osprey 1.1.6 更新公告

发布日期：2026-11-03

## 这次修复

**取消本地模型下载后软件崩溃。**

原因：

- 下载窗口销毁后，150ms 的自动启动回调仍可能触发下载
- 下载线程完成后仍会向已销毁的 Tk 窗口投递进度/完成回调

现在：

- 关闭窗口会取消尚未触发的启动回调
- 窗口关闭后下载线程不再访问 Tk 控件
- 下载未真正开始就取消时，直接关闭，不启动线程
- 下载进行中取消时，先终止 ollama pull，等工作线程结束后再销毁窗口
- 新增“取消发生在下载启动前”的回归测试

## 保留的行为

- 选择 3B/7B 时检查是否安装
- 未安装时弹窗显示大小（3B 约 3 GB / 7B 约 6 GB）
- 确认后显示百分比进度条
- 可取消，不再自动下载
